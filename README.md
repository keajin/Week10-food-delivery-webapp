# Week10-food-delivery-webapp
COMP2110-week10-group
Step 1. Define Web Application
Form a group with your nearby classmates, groups of 3 or more are encouraged, but flexibility is allowed if needed. In your group, brainstorm and decide on a project idea of your choice. As the delivery of this step, write a brief project description that answers:

What problem does the app solve?
Who are the target users?
What are the key features?
Commit to your workshop week10 README.md and push changes

Step 2. Analysis Web Application
Then, for your chosen project, perform a basic requirements analysis in a group:

At least 3 core functional requirements (what the app must do)
At least 2 non-functional requirements (such as performance, security, usability)
Commit to your workshop week10 README.md and push changes

Step 3. Estimate Timeline
Based on your requirements:

(in group) Identify which team member(s) will work on each task
(Individual) Break down your assigned component into smaller tasks and estimate how long each will take (in hours, with specific days/weeks)
(in group) Provide a basic timeline showing the expected schedule
Commit to your workshop week10 README.md and push changes

Step 4. Planning
List and briefly explain the web stack components you will use at each layer. For example,

Frontend (HTML, CSS, JavaScript)
Backend (Node.js, Express)
Database (MongoDB, or mock data for now)
Communication (HTTP using Fetch API)
Commit to your workshop week10 README.md and push changes

Draw a UML Sequence Diagram that shows:

The user’s interaction with the browser (frontend)
The browser’s request sent to the server (backend)
The server’s communication with the database (if needed)
The server’s response back to the browser
How the browser updates the page for the user
Any other sequences needed
You can use full tool with VS Code+Java on extensions of PlantUML and its preview, or a light tool web sequence diagram, or tools like Lucidchart, Microsoft Visio, Microsoft PowerPoint, or even hand-draw the diagram and upload a photo. A brief guidance is available in week 9 lecture slides.

Commit and push a photo of diagram to workshop week10 folder

Across Steps for planning and development, Set up a GitHub Project board for your group to organise your teamwork.

(in group) Create a GitHub repo for this project (no need to complete it) and make group members collaborators
(in group) Create a GitHub Project board for your group
(Individual) Add each app task as an Issue and connect it with GitHub repo
(Individual) Assign yourself to Issues (tasks) you created
(Individual) Drag each issue to its progress into a real status column: Backlog, Ready, In Progress, In Review, or Done
(Individual) Keep updating and detailing the board regularly as work progresses. Move Issues across columns as your tasks advance
